# HwF Player

Android-приложение для прослушивания музыки на устройстве, созданное для аудиоплеера Shanling M3 Ultra. Проект находится в разработке.

Приложение использует Kotlin, Jetpack Compose и AndroidX Media3. Минимальная версия Android — 10 (API 29).

## Сборка

Откройте проект в Android Studio, установите Android SDK с API 37 и используйте JDK 17. Для сборки отладочной версии выполните:

```sh
./gradlew assembleDebug
```

В текущей конфигурации release-сборка подписывается локальным отладочным ключом и не предназначена для публикации в магазине.
